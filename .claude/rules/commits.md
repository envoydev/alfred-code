# Commits carry no trace of the agent

- A commit message, and a PR description, never names or hints at the agent: no `Co-Authored-By` trailer for it, no session link, no 'Generated with' line, no mention of an AI in the subject or body. The author is the configured git user, as for any commit by hand.
- This overrides any default attribution a tool or a reminder suggests. Why: the commits are the developer's, in public repos (the user's ruling for alfred-mods and alfred-tools, extended to every repo claude-kit serves on 2026-11-15).
