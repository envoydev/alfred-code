# Minimal APIs - version-gated additions

Version-gated additions to the endpoint surface, each marked with the runtime that brought it: on the .NET 10 floor all of them are available, and a project below it (.NET 8 / 9) skips the ones its runtime lacks. The rules in the skill body stand unchanged; open this when wiring one of these or weighing Native AOT.

- **.NET 9+:** the built-in OpenAPI generator (`AddOpenApi()` / `MapOpenApi()`) supersedes Swashbuckle - the OpenAPI document skill owns the generator pick and the switch.
- **.NET 10+:** first-party validation (`AddValidation()`, the `Microsoft.Extensions.Validation` package) runs `[Required]` and friends from `DataAnnotations` without a third-party library, discovers the handler parameter types itself, and applies an endpoint filter for you. Its rule surface grows release by release - class-level `IValidatableObject`, async `IAsyncValidatableObject` with services resolved from the validation context - so verify the exact capability set via the documentation server before adopting it rather than trusting a recalled gap. The house default stays the validator-in-a-filter approach in the skill body (it works below the floor too and keeps one rule language per surface - the library pick belongs to the web hub).
- Rate limiting (`AddRateLimiter`, .NET 7+) and output caching (`AddOutputCache`, .NET 7+) both attach to a group with a single fluent call. Output caching's rules belong to the web hub; rate limiting has no deeper owner in the set - define a named policy at registration and attach it to the group with `RequireRateLimiting`.
- **.NET 8+ Native AOT:** minimal APIs (partial support) and gRPC (supported) publish under Native AOT; MVC does not. To stay AOT-clean, publish with `PublishAot`, let the request-delegate generator source-generate the endpoint plumbing instead of reflection-emitting it, and register a `System.Text.Json` `JsonSerializerContext` source generator to cover both bind-in and serialize-out. Reflection-based (de)serialization and reflection-heavy libraries in the request path break AOT - build with the AOT-analysis warnings on to catch them. Payoff is faster startup, lower memory, and a small self-contained binary.
- **.NET 10+:** `TypedResults.ServerSentEvents(...)` is a first-class return type for one-way server-to-client push - progress, live feeds, token streaming - over a plain HTTP connection, lighter than SignalR or raw WebSockets when you need push, not a duplex channel. This skill owns only the return type; pick SSE over SignalR when the push is one-way, needs no groups or reconnect replay, and every client speaks plain HTTP.
