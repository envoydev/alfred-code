# Evidence appendix - the runs these design rules were written from

An audit appendix, not a run-time load: read it when a rule in SKILL.md looks like ceremony, never
while designing.

- **Consult the architecture doc SCOPED (method step 1).** The whole-file pull is ~9.6k tokens and
  was the single largest result of its sessions; the grep-plus-listing consult delivered the same
  orientation for ~1.3k - an 86% cut.
- **`Oriented:` cites evidence, not a summary claim (method step 1).** One plan's header claimed a
  full doc read plus a six-surface symbol pass; the session held neither.
- **The verdict is judged against `Asked:` (method step 3).** A plan that fit the code as a
  side-by-side prototype, where the user had asked for the old path to be REPLACED, was rejected
  after its whole build window - 23.9M cache-read.
- **Strip the format skill's banner (Plan format).** Measured in five bundles: the format skill's
  banner landed in durable plan files recommending a dispatch method the run's own approved mode
  excluded, and a plan file outlives the session that made it, so the wrong
  advice is read by every later seat.
- **Scope a prior plan read (Plan format).** With nothing loading the format, one run whole-read an
  unrelated 275-line ticket plan - the session's largest result and biggest context spike.
